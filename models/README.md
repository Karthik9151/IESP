# IESP runtime model artifacts

The authoritative MeAJOR dataset is intentionally kept outside GitHub.

Runtime models are generated by the manual GitHub Actions workflow:

`.github/workflows/build-model-release.yml`

The workflow:

1. Downloads MeAJOR record 18471483 from Zenodo.
2. Verifies the published dataset MD5.
3. Runs the accepted M1 preprocessing/split pipeline.
4. Verifies the required M1 fingerprint and split sizes.
5. Trains the phishing and priority baselines.
6. Publishes the model binaries, metadata, metrics and a SHA-256 manifest to GitHub Release `models-v1`.

The Docker image downloads only the published model artifacts during image build and verifies their SHA-256 hashes and M1 contract before the API starts.

Expected runtime paths inside the container:

- `models/phishing/phishing_pipeline.joblib`
- `models/priority/priority_pipeline.joblib`

Do not commit the MeAJOR dataset or generated model binaries to Git history.
